# 落笔（Android）

把一段话（口播、想表达的意思、疑问）变成一篇完整文章，再一键变成小红书图、长图、HTML，或同步到 Notion / 语雀 / Telegraph / 自定义博客接口。
以「小红书助手 v2.9」源码为基础复制扩展（原项目未改动），独立包名 `com.scarlett.luobi`、独立签名钥匙。

- 版本：2.1.0（versionCode 28），minSdk 29，targetSdk 35
- 技术：Kotlin + Jetpack Compose + Room + WorkManager + EncryptedSharedPreferences

## 2.1.0 改动（事实校对重做 · 方案 A）
- **又快又准**：先分拣句子（硬事实 / 观点 / 描写），只核硬事实；数字、引语优先核；结果逐条流进列表。每个结论必须带资料原句 + 链接，否则一律「无法核实」。保留预检、并发、超时重试、部分报告、WorkManager 后台、通知与红点、同篇替换、可停止。
- **逐条修**（底部弹层）：原句 / 错在哪 / 证据原文与链接 / 最小改动 diff；采纳、换个改法（1–2 个备选）、手动改（跳编辑器并选中该句）、忽略。无法核实给稳妥说法。第一次改动前自动存快照，一键还原。
- **风格把关**：只看改过的段落及前后段，按论点 / 衔接 / 语气（AI 腔）给建议卡，逐张采纳。
- 保留 DeepSeek 深度思考开关与温度滑杆。数据库结构不变（仍为 v6），新数据存在报告 JSON 里。
- 截图：`screenshots/v2.1/`。

## 1.17.0 改动（事实校对：细节级核查 + 后台运行）
- **流水线**：校对模型先把文章拆成「说法」，每条再拆成原子细节（人物/时间/地点/事件/关系/引述归属/范围），并标类型（可核实事实/引述归属/修辞渲染/观点）。自动补两类隐含检查：1928 年 6 月前写「北平」（时代错置）、「民国初年」配 1920 年代例子（时间口径）。
- 每个细节 2–3 条**带实体**的检索词（不拿文章主题去搜）；元宝优先 → Kimi → DeepSeek → 中文维基 → 英文维基 → 维基语录，取前两条全文；按实体过滤段落，泛泛资料（只讲「民国风气」之类）不进裁决。
- 裁决：已印证 / 部分对 / 有出入（给改写）/ 无法核实 / 渲染无出处 / 观点不校。引述归属按「意思」判；每个结论必须有资料里的原句 + 链接，引文在资料里找不到就降为无法核实；无法核实前会换说法再搜一轮，并列出试过的查询。并发 4 路，沿用 429 退避与元宝月度计数，遵循 DeepSeek 深度思考开关。
- **后台**：WorkManager 加急前台任务。通知「正在校对《标题》· n/N」；完成通知「《标题》校对完成 · 有出入 x · 部分对 y」，点开直达结果弹层。每核完一条存进 Room（`fact_jobs` 表，数据库 v6），进程被杀后接着跑；同一篇不会重复启动。Android 13+ 首次使用时请求通知权限。
- 阅读页搜索图标：跑着时显示细进度环（不弹窗），有没看过的结果显示红点，看过即消失。
- **结果弹层**（方案 A）：顶部列出本次用到的资料来源；有出入/部分对/已印证三格计数，其余三类收在「其他」行；每条说法一张卡，逐行列细节（结论标签、原句、来源链接、改写 + 应用勾选）。
- 截图：`screenshots/v1.17.0/`（丁玲文章的结果弹层、阅读页红点、后台进行中）。

## 构建
```bash
echo "sdk.dir=/opt/android-sdk" > local.properties
# 签名：../signing/signing.properties（storeFile/storePassword/keyAlias/keyPassword），不在源码包内
./gradlew :app:testReleaseUnitTest :app:assembleRelease
```
没有 signing.properties 时会产出未签名 release 包。

## 代码结构（app/src/main/java/com/scarlett/luobi）
| 文件 | 内容 |
|---|---|

| Data.kt | Room 实体（Note 版本链 / Template / CleanTpl / Channel）、内置 5 模板 + 标准清洗、Settings、Secure（加密存储） |
| Api.kt | OpenAI 兼容调用（沿用 Providers / 报错）；clean（固定 DeepSeek）、write、rewrite、test；配图 |
| Gen.kt | WorkManager 后台生成 / 改写，完成通知 |
| MainActivity.kt | 导航、写作三步流程、最终提示词预览 |
| Reader.kt | 结果页（阅读 / 配图、版本、底栏同尺寸渠道格子：小红书 + 置顶渠道 + 更多，可横向滑动） |
| Panel.kt | 分享面板四组渠道及动作 |
| Channels.kt | Notion、语雀、Telegraph、自定义端点、HTML 富文本 / .html 文件、系统分享到指定 APP |
| Render.kt / Share.kt | 照搬小红书助手：卡片、长图、Share.sendImages（只改配色、FileProvider authority、相册名） |
| SettingsUi.kt | 设置首页与全部子页面 |
| Comp.kt / IcData.kt / Theme.kt | P3 组件、icons.py 线条图标（PathParser 渲染）、配色 |

## 意图变量规则
- 变量 `{名字}`，名字只认汉字/字母/数字/下划线（JSON 示例的花括号原样保留）。
- 值原样替换；一行里只要有一个变量为空或不存在，整行删除。
- 写作模板引用当前清洗模板不输出的字段 → 编辑器黄色警告；切换清洗模板 / 删字段时列出受影响模板。
- 最终提示词 = 填好的模板 + 篇幅行（「设置 → 篇幅设置」的默认篇幅，如「篇幅：中篇，正文字数控制在 400–800 字之间。」）；写作时 system 消息要求输出 JSON {title, body, tags}，解析失败按纯文本兜底。

## 1.5.0 改动（方向 A · 冷白磨砂）
- **金句变标题（修复）**：解析器把整段 `**…**`（5–42 字）当成 H2，这是 1.0 旧格式遗留；1.3 起 AI 用 ** 标金句，单独成段的金句被放大成小标题。现在整段加粗只有 ≤14 字且无句读才算小标题，其余是正文字号加粗；`#` 开头但像句子（有句读或 >24 字）的也降为加粗正文；提示词明确金句不能用 #。阅读页、长图、HTML/Markdown/Notion/Telegraph 共用同一解析，一并修好。
- **统一圆角**：新增 Shapes.kt，全 App 唯一的连续曲率（squircle，超椭圆 n=4、角区 1.28×）形状族；刻度 8/14/20/24/28dp + 全圆胶囊，同一曲线。卡片/弹层/对话框 28dp，按钮/标签/胶囊/浮动圆全圆。代码里已无 RoundedCornerShape/CircleShape（Theme 里仅作 Material 兜底，所有组件显式传 Squircle）。
- **浮动磨砂**：主导航、阅读页分享栏、返回圆、右上动作组、配图页/插图底栏都是浮动胶囊。Android 12+ 用 RenderEffect 真模糊（内容录进 GraphicsLayer，再录一份模糊副本给胶囊画）；11 及以下回退半透明白。
- **分享栏网格**（detail.png）：等宽格，图标框 24dp（图标 20dp），间距 3dp，标签行高 14dp（10sp，单行，去字体内边距），整组垂直居中，整格可点；选中只换颜色。主导航同一网格。
- 写作页：紧凑标题 + 行内步骤条；输入区不再卡片套卡片；主按钮固定在浮动导航之上。
- 文案库：标题一行 + 摘要一行 + 弱化信息一行；筛选（全部/收藏/模板）统一分段胶囊，选中实心。
- 设置：分组列表（写作 / 分享与图片 / 其他），18dp 线性图标列、右侧弱化值、›，分隔线从文字起点开始；更多面板同一行网格。
- 单元测试 86 个全部通过（新增 GoldenSentenceTest 4 个，用她的原句）。

## 1.4.0 改动
- **模板提示词缺段落（修复）**：1.3 的填值规则是「一行里任一变量为空/未知就整行删」，模板里「创作的主题围绕{疑问}{观点}{想写什么}，你要写一篇完整的中文公众号长文。默认要求：」只要有一项没识别到就整行消失，预览和实际发给模型的提示词都缺这一句。现在：从不删句子；有值替换，连写的多个占位只拼有值的（用「；」隔开）；空的只去掉占位；未知变量原样保留并在预览里标黄；只有纯「标签：{变量}」行全空时省略。
- **篇幅**：模板里自己写了「篇幅：…」行时以模板为准，不再追加设置里的篇幅（预览会注明，写作页篇幅行显示「模板已指定」）；没写才追加设置篇幅。
- 生成（含失败重试）在发送前按模板库里的**当前**模板重建提示词。
- 模板编辑自动保存（返回键 / 手势 / 左上角都会保存并提示「已保存」）；模板名去重；「我的」徽标；推荐同名时优先「我的」；预览下方「模板「X」最后修改 HH:mm · 编辑」。DB v3（templates.updatedAt）。
- 阅读页分享栏改为悬浮胶囊（半透明白 + 细边 + 阴影，正文在下面滚动），1–6 格等分，「更多」固定最右；配图页、插图底栏同样式。
- 纯数字小标题（## 1 / 一 / 01）显示为蓝色小序号「01」+ 短线（阅读页和长图）；OUT_RULE 要求 AI 写有内容的小标题。
- 审查修正：标签下蓝短条改细线；模型选择改单选列表；篇幅改普通设置行；右上图标统一 22dp 中性色；标签平时纯蓝字、点「编辑」才可删；去掉「{原文}」字样；已完成步骤收成一行；更多面板分隔线缩进、图标统一色；模板编辑「默认模型」改单选列表。
- 单元测试 82 个全部通过（新增 TemplatePromptTest 10 个，含她的原文）。
